# 实验1：带键盘事件的计算器

Qt Widgets 实现的四则运算计算器，支持鼠标点击与键盘输入，两套输入复用同一套槽函数。

## 功能
- 上下双显示：上行显示完整表达式（按 = 后定格为"算式 ="），下行显示当前输入/结果
- 四则运算（+ − × ÷）与括号 ( )，支持优先级（调度场算法求值）
- 隐式乘法：数字/结果/ ) 之后按 ( 自动补 ×
- 小数输入、退格（⌫，可回退到表达式）、清除（C）
- 异常输入处理：连续小数点、连续操作符、前导 0、除数为 0、括号不匹配、计算完成后继续输入、等号时未闭合括号自动补全
- 键盘输入：数字 0~9、`.`/`,`、`+` `-` `*` `/`、`(` `)`（Shift+9/0）、`Enter`/`=`、`Backspace`、`C`/`Del`/`Esc`
- 深色手机计算器风格样式表，功能键/运算符/数字键三色区分

## 测试要点
| 操作 | 预期结果 |
|---|---|
| 连续按两次 `.`（如 1.5.） | 第二次小数点被忽略，显示 1.5 |
| 输入 5 后连续按 + × | 操作符被替换为 ×，不产生错误 |
| 5 ÷ 0 = | 显示"错误：除数为 0"，锁定输入 |
| 错误后按数字 | 无响应，必须按 C 清除 |
| 3 + 4 = 后再按 × 2 = | 结果 14，支持连续运算 |
| ( 1 + 2 ) × 3 = | 上行显示算式，结果 9 |
| 1 + 2 × 3 = | 优先级正确，结果 7 |
| 2 + 3 ) = | 右括号自动补全，结果 5 |
| ) 5 （expr 以 ) 结尾后按 5） | 自动补 ×，表达式 ")×5" |
| 2 + 3 ( 无配对 ) | 等号时自动补全为 (2+3)，结果 5 |
| 键盘输入 12*3= | 与鼠标点击结果一致，显示 36 |
| 键盘 Shift+9 / Shift+0 | 等价于鼠标点击 ( ) |

## 构建（Qt 6.9.2 + CMake）
```bash
cmake -B build -S .
cmake --build build
./build/Calculator   # Windows: build\Calculator.exe
```
